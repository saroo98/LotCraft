# LotCraft 1.1.0 Known Limitations

Only limitations verified from the delivered source or build environment are listed.

1. **The final rebuilt interaction paths still require physical confirmation.** The currently attached AUDUSD panel visually confirmed that price lines paint behind the panel and the Order type control no longer overlaps its label. The final rebuilt EX5 was installed after the precise-caret, partial-edit, empty-label, copy-feedback, thresholded full-panel snapshot drag, enlarged-handle, pointer-coordinate calibration, time-ordered lightweight fast-drag, and panel-drag background-work suppression changes. Reattachment may show a DLL/security permission dialog that automated control cannot accept. Precise click placement, Backspace/Delete, double-click/Ctrl+A selection, the copy checkmark, smooth panel dragging without two-pixel oscillation or calculation hitches, rapid handle movement, stationary handle press-and-hold, handle coupling, lifecycle changes, and runtime Experts/Journal review remain manual acceptance items.
2. **DLL permission is mandatory.** The EA fails initialization when `Allow DLL imports` is disabled because Unicode clipboard support, the native F9 order dialog, and pointer-release recovery use an isolated Win32 layer.
3. **Instant Entry is market-bound.** Instant sizing and display follow current Ask for Long and Bid for Short. Raw Entry text can be edited while focused, but commit, steppers, and the Entry handle cannot establish a durable nonmarket Instant entry. Pending mode provides durable manual Entry. This is the conservative resolution of conflicting editable-Entry and executable-market-price requirements.
4. **Pending expiration is limited to GTC or DAY.** A symbol that supports only specified-date expiration is rejected because the required visible control inventory contains no expiration input.
5. **New orders are blocked on a nonhedging account when the current symbol already has a position.** This avoids silently aggregating, reducing, or reversing a net position and avoids applying the requested SL/TP to a combined position.
6. **The produced installer is not Authenticode-signed.** PE identity, version resource, architecture, checksum, and reproducible bytes are tested, but publisher signing was not available in this environment.
